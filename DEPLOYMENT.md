# GitHub Pages setup

The card is published directly from the repository's `main` branch on GitHub Pages. Upload `index.html`, `styles.css`, and `script.js` to the repository root; the selected photo file must also be in the root. Pages is configured to publish `main` from `/ (root)`.

The PIN and birthday note are part of the public JavaScript. This is only a casual screen lock: anyone can inspect or bypass it. The 17-day release uses the visitor's device clock and is not secure. Do not use this version to protect private information.

The photo included in the repository is public and appears before and after the PIN screen. A photo selected with the picker replaces it only in that browser and is not uploaded to GitHub.

The WhatsApp button opens a prefilled message for you to review and send. The share link is the GitHub Pages URL.
